# lvgl_game

这是一个基于windows加lvgl框架制作的单文件掌机游戏模拟器，可以实现nes和gba游戏模拟，多倍点对点显示

## NES游戏说明 视频链接 https://www.bilibili.com/video/BV1Xt7wzXEiF

支持双人操作，支持存档

键盘操作按键：

| NES按键      | 键盘按键 | NES按键      | 键盘按键  | NES按键  | 键盘按键  |
| ------------ | -------- | ------------ | --------- | -------- | --------- |
| **P1**：上键 | 键盘W    | **P2**：上键 | 上箭头    | Start键  | 键盘Enter |
| **P1**：下键 | 键盘S    | **P2**：下键 | 下箭头    | Select键 | 键盘Ctrl  |
| **P1**：左键 | 键盘A    | **P2**：左键 | 左箭头    |          |           |
| **P1**：右键 | 键盘D    | **P2**：右键 | 右箭头    |          |           |
| **P1**：A键  | 键盘I    | **P2**：A键  | 数字键盘5 |          |           |
| **P1**：B键  | 键盘J    | **P2**：B键  | 数字键盘1 |          |           |
|              |          |              |           |          |           |

## GBA游戏说明 视频链接 https://www.bilibili.com/video/BV1XAM8z3EUR

支持3倍加速，支持关闭游戏自动存档

键盘操作按键：

| GBA按键 | 键盘和手柄按键                        | GBA按键  | 键盘和手柄按键           |
| ------- | ------------------------------------- | -------- | ------------------------ |
| 上键    | 键盘W \| 手柄左摇杆上 \| 手柄左侧上键 | Start键  | 键盘Enter \| 手柄Start键 |
| 下键    | 键盘S \| 手柄左摇杆下 \| 手柄左侧下键 | Select键 | 键盘Ctrl \| 手柄Select键 |
| 左键    | 键盘A \| 手柄左摇杆左 \| 手柄左侧左键 |          |                          |
| 右键    | 键盘D \| 手柄左摇杆右 \| 手柄左侧右键 | 存档键   | 键盘P \| 手柄Y键         |
| A键     | 键盘I \| 手柄A键                      | 加速键   | 键盘空格 \| 手柄RT       |
| B键     | 键盘J \| 手柄B键                      |          |                          |
| 左扳机  | 键盘Q \| 手柄左扳机                   |          |                          |
| 右扳机  | 键盘O \| 手柄右扳机                   |          |                          |
